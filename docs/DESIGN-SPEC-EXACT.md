## 四、交互（对齐 HTML 的 JS 行为）

- 路由：13 屏间跳转（`data-go`），支持 hash 直达（`#s11`）
- 录音：点击 mic → 进入 s02 并开始计时；1 秒 tick，按 `TRANSCRIPT` 时间轴逐条追加片段并自动滚到底；暂停/继续切换图标；停止 → 跳 s03
- 断线模拟：录音第 8 秒自动跳 s06（可保留为 debug 演示或由真实断线事件触发）
- 过滤 chips：点击切换 `on` 态；转写页按说话人过滤列表项
- 开关（说话人分离 / 音频留存）：点击切换
- Toast：导出/分享/复制 后顶部浮出深色 Toast，约 2.2s 自动消失
- 模式分段（会议/访谈/灵感）：切换并同步录音页副标题
